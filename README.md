# mlnyc-records

A command line tool used to create MARC records for Teacher Sets based on JSON exported from the MyLibraryNYC Application. 

These scripts require an export of data from the Curate tab of the MLN App and access to the the WorldCat Metadata API.

## Version

> 0.1.0

## Setup
### Install with `uv`
1. Clone repository
2. Navigate to project directory in terminal
3. Install dependencies with `$ uv sync`


## Usage
```
$ mlync build
```
